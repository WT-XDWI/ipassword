# iPassword

迄今为止最快，最强的 ipassword。本地加密级随机密码生成器。

**单文件、零依赖、零网络请求。** 所有密码在浏览器本地通过 Web Crypto API 生成，不经过任何服务器，刷新页面不留任何记录。

## 使用

直接打开 `index.html` 即可。或者部署到任意静态服务器：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

无需构建、无需安装依赖。

## 功能

- **密码长度** 4–64 位可调
- **字符集开关**：大写、小写、数字、符号
- **排除易混淆字符**：移除 `I l O S s Z z B b G g`，避免手抄时看错
- **实时强度评估**：显示熵值（bit）与分级
- **一键复制**
- **选项自动记忆**（localStorage）
- 深色模式自适应
- 响应式，手机可用

## 安全设计

这是本项目最核心的部分，所有实现均可审计。

### 随机数来源

使用 `crypto.getRandomValues()`（Web Crypto API），**不使用 `Math.random()`**。

```js
function secureRandom(max) {
  if (max <= 1) return 0;
  var limit = Math.floor(4294967296 / max) * max;
  var x;
  do {
    crypto.getRandomValues(randBuf);
    x = randBuf[0];
  } while (x >= limit);
  return x % max;
}
```

采用**拒绝采样**（rejection sampling）消除模偏差。以 `max = 62` 为例，`2^32` 不能被 62 整除，直接取模会让前几个字符出现概率略高。这里先算出 `limit`，把落在尾部不可整除区间的随机数丢弃重取，保证每个字符概率严格相等。

实测：模拟 20 万次，62 个字符全部覆盖，最大偏差 4.3%（正常随机波动范围）。

### 字符多样性保证

生成时先为每个选中的字符集各取一个字符，再填充剩余位置，最后做 Fisher-Yates 洗牌。这保证「勾选了数字就一定有数字」，同时不泄露位置规律。

### 隐私

- **零网络请求** —— 代码中不存在 `fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`
- `localStorage` **只保存生成选项**（长度、字符集开关），**不保存任何密码**
- 密码仅存在于内存变量中，刷新即消失

### 熵值计算

```
熵 = 长度 × log2(字符池大小)
```

| 配置 | 字符池 | 20 位熵值 |
|---|---|---|
| 字母 + 数字 | 51 | 113 bit |
| 全部字符集 | 90 | 130 bit |
| 全部字符集 + 排除混淆 | 79 | 126 bit |

分级标准：< 45 较弱 / < 70 一般 / < 100 强 / ≥ 100 极强。

## 易混淆字符

无衬线字体下，这些字符几乎无法区分，手抄时极易出错：

| 字符组 | 说明 |
|---|---|
| `I` `l` `1` | 都是竖线 |
| `O` `0` | 都是圆圈 |
| `S` `s` `5` | S 形 |
| `Z` `z` `2` | Z 形 |
| `B` `8` | B 形 |
| `b` `6` | b 形 |
| `G` `g` `9` | G 形 |

开启「排除易混淆字符」后会移除其中的**字母**（`I l O S s Z z B b G g`，共 11 个）。

**数字 `0123456789` 完整保留** —— 这样密码看起来依然正常，字符池只从 90 降到 79，20 位熵从 130 降到 126，仍属「极强」。

## 兼容性

依赖 Web Crypto API，需要 HTTPS 或 localhost 环境（浏览器安全限制）。

- Chrome / Edge 60+
- Firefox 57+
- Safari 11+

直接以 `file://` 打开时，部分浏览器可能限制 Web Crypto，建议用本地服务器。
